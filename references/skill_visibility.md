# Flutter Forge Reference - 可见性与会话状态

连续对话中，用户需要知道 flutter-forge 是否在工作。采用任务级标记，不干扰但可感知。

## 可见性标记

### 标记规则

- 轻量任务：回复开头带一行 `[ff] 轻量任务，直接执行`
- 中等任务：回复开头带 `[ff] 中任务 + 基于什么规则（如有规则卡）`
- 大任务：每个角色切换时带 `[ff] 角色名：正在做什么`，结束时带 `[ff] 完成`
- 后续对话中 flutter-forge 继续介入时，每条关键回复开头带 `[ff]` 标记

### 标记格式

```
[ff] 轻量任务，直接执行
[ff] 基于规则卡（读取 rule_card.yaml 中的 state_management + routing 等关键字段）生成代码
[ff] 需求分析师：正在拆解 PRD
[ff] 完成，已生成订单列表页骨架
```

规则卡摘要只取 2-3 个关键字段（如状态管理、路由、网络层），不要把整个规则卡内容塞进标记里。没有规则卡时写 `[ff] 基于项目现有风格生成代码`。

### 不标记的情况

- 用户问的是纯知识问题（"GetX 怎么用"），flutter-forge 未介入项目代码
- 闲聊、确认、追问等不涉及任务执行的对话

## 会话状态

维护 `.flutter-forge/session.md`，记录当前会话的 flutter-forge 工作状态。用户可以随时问"flutter-forge 现在是什么状态"来查看。

### 写入时机

- 任务开始时：写入任务分级、规则卡状态
- 规则卡加载时：写入规则卡摘要
- 任务完成时：更新最近一次操作

### 文件格式

```markdown
# Flutter Forge Session

- 规则卡：已加载 / 未加载
- 规则卡摘要：从 rule_card.yaml 提取 2-3 个关键字段（如状态管理、路由、网络层）
- 当前任务：轻量任务 / 中等任务 / 大任务
- 最近操作：具体做了什么
- 更新时间：YYYY-MM-DD HH:mm
```

### 读取时机

- 用户主动问"flutter-forge 状态"、"现在什么模式"等
- 不主动输出，不每轮回复都展示
